Real-Satellite Trained ESRGAN-MSI

Trained from scratch on over 7,700 real paired satellite patches from Sen2Venµs (5m) and WorldStrat (2.5m). Employs 4-channel Residual-in-Residual Dense Blocks (RRDB) with Wald-constrained downsampling loss. Achieves 39.19 dB PSNR at 0.33s inference latency.

LDSR-S2 Latent Diffusion Baseline

113-million parameter latent diffusion model adapted for multispectral remote sensing. Provides stochastic iterative DDIM sampling steps (T=6 to T=25) serving as an academic benchmark against our direct GAN generator.

Wald Synthesis Protocol (1997)

Strict remote sensing validation framework: synthesized high-resolution imagery downsampled via sensor Point Spread Function (PSF) must reproduce native observations within rigorous physical tolerances: $\mathbb{E}[\|\mathbf{y} - (\hat{\mathbf{x}} * \text{PSF})_{\downarrow 4}\|_1] < \epsilon$.

GIS Product Geotransforms

Rasters are exported as standard GeoTIFF rasters with intact GDAL Affine matrices, projection metadata in EPSG:4326 (WGS 84), and floating-point radiometric values directly ingestible into QGIS, ArcGIS Pro, and Google Earth Engine.
